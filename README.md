# Прогнозирование стоимости недвижимости

Учебный командный проект 4-го курса: построение и сравнение моделей регрессии
для прогноза цен на недвижимость, а также Streamlit-приложение с формой
прогноза, дашбордом и справочной информацией.

**Авторы:** Гумеров Алик, Руднев Илья · 4 курс · 09.2026

---

## Что делает проект

1. **EDA и предобработка** — анализ датасета турецкого рынка недвижимости
   (403 487 объявлений, 2018–2019): пропуски, выбросы, дубликаты,
   категориальные признаки, winsorization, логарифмирование цены.
2. **Feature Engineering** — target encoding (`city`, `room_count`,
   `district_grouped`), one-hot (`sub_type`, `heating_type`,
   `price_currency`), скалирование (`size`, `building_age`, `tom`).
3. **Моделирование** — обучение и сравнение 4+ моделей:
   Ridge, Decision Tree, Random Forest, HistGradientBoosting,
   Gradient Boosting (финальная). Подбор гиперпараметров через
   `RandomizedSearchCV`.
4. **Приложение** — Streamlit-приложение с тремя вкладками:
   - **Прогноз** — форма ввода характеристик объекта + вывод цены.
   - **Дашборд** — статистика, графики, сравнение моделей.
   - **Справка** — описание полей, модели и её ограничений.
